# Demo production templates

These files are editable presentation and production templates. They are not
evidence that any product capability, result, metric, customer, person, or
commercial outcome exists.

## Claim authorities

Before replacing a bracketed prompt, verify the statement against the relevant
authority:

- [Product requirements](/docs/PRD.md)
- [Technical requirements](/docs/TRD.md)
- [Product definition](/docs/PRODUCT.md)
- [Demonstration spine](/docs/research/ideation/demo-spine.md)

Bracketed prompts require verification. Record the supporting authority,
confidence, owner, and fallback wording in the investor evidence template.
Leave a prompt bracketed when verification is incomplete.

## Demonstration policy

The preliminary run uses synthetic data. Do not substitute personal,
confidential, or production records. If a live provider is unavailable, any
provider fallback must be visibly labelled on screen and verbally disclosed
before its output is presented. Keep the failed live attempt distinct from the
prepared fallback.

## Template index

- `deck/demo-day-template.html`: editable presentation deck.
- `deck/investor-template.html`: editable investor deck and unconfigured video
  stage.
- `deck/visual-prompts-template.md`: reusable visual asset briefs.
- `scripts/demo-day-template.md`: presenter route, talk track, and questions.
- `scripts/demo-video-director-5min-template.md`: timed director blocks.
- `scripts/demo-video-director-alt-template.md`: alternate edit plan.
- `scripts/investor-evidence-template.md`: claim-to-proof matrix.

Open either HTML file directly in a browser. Edit the outlined fields, use the
on-screen controls or keyboard, and print to produce one slide per page. The
templates intentionally contain no bundled media or external resources.
