# Test-user selection scorecard

Use this scorecard after the test user reads the two-sentence explanation for
each idea and, if needed, the complete briefs. Do not explain which option the
team currently prefers before collecting the first reaction.

## Problem summary for the test user

A shipping team receives many different emails in one inbox. The product must
find requests to compare a Shipping Instruction against a draft Bill of Lading,
check seven shipment details, show any errors, and ask a person for help when it
cannot decide safely.

## Idea A: LadingLens

LadingLens turns a mixed shipping inbox into a clear work queue where every
email is completed, dismissed for a stated reason, or waiting for a named
action. For document checks, it confirms the correct Shipping Instruction and
draft Bill of Lading are present, compares seven shipment details, shows the
exact source proof, and sends uncertain cases to a person.

## Idea B: SameStory

SameStory reads the email subject, newest message, and actual attachments as
separate accounts because shipping emails can say one thing while their files
contain another. It proceeds only when those accounts support the same action;
otherwise it shows the contradiction, requests review, and performs the
required SI-to-BL comparison once the request is verified.

## First-reaction questions

Ask these before showing architecture or rubric material:

1. In your own words, what does Idea A do?
2. In your own words, what does Idea B do?
3. Which idea did you understand more quickly?
4. Which problem feels more important in a real shipping inbox?
5. Which idea would you most want to see demonstrated?

## Forced choice

Complete all four prompts:

- If only one could be built, I would choose:
- The most convincing reason is:
- My biggest concern about that choice is:
- One thing I would remove or simplify is:

## Selection rule

Prefer the idea that the test user can explain accurately without borrowing our
phrasing. Use the numerical result as supporting evidence, not as a substitute
for their reasoning.

If the totals are within three points, choose based on the forced-choice answer
and demonstration preference. Do not combine both headlines; the selected idea
must remain understandable as one product promise.
