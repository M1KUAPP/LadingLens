## File descriptions

- **`sdoc-hackathon-bundle.zip`**: Contains the standalone dataset bundle
  including `inbox/` email records, `attachments/` with Shipping Instructions
  (SI) and draft Bills of Lading (BL), `sample_submission.json`, and the
  `loader.py` data helper script.
- **`sdoc-hackathon-docker.zip`**: Contains the local Docker evaluation server
  configuration (`docker-compose.yml`) providing the HTTP evaluation endpoint at
  `http://localhost:8080`.
- **`Shipping Document Verification Use Case.pdf`**: The official problem
  statement specification document covering operational context, the 7-field
  discrepancy scope, advanced challenge stages, and evaluation formatting.
